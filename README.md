# B站兴趣画像与推荐算法控制插件

## 🎯 功能概述

这是一个强大的浏览器扩展插件，不仅可以收集和分析你的B站浏览行为，更重要的是能够**直接更改B站的推荐算法**，让你摆脱信息茧房，体验不同时期的推荐内容。

## 🌐 浏览器兼容性

### ✅ 完全兼容的浏览器
- **Google Chrome** (推荐)
- **Microsoft Edge** (基于Chromium)
- **Opera** (基于Chromium)
- **Brave Browser** (基于Chromium)
- **Vivaldi** (基于Chromium)
- **Firefox** (109.0+)

### 📦 安装说明

#### Chrome/Edge/Opera/Brave/Vivaldi
1. 下载所有文件到本地文件夹
2. 打开浏览器，进入扩展管理页面：
   - Chrome: `chrome://extensions/`
   - Edge: `edge://extensions/`
   - Opera: `opera://extensions/`
   - Brave: `brave://extensions/`
   - Vivaldi: `vivaldi://extensions/`
3. 开启"开发者模式"
4. 点击"加载已解压的扩展程序"
5. 选择包含插件文件的文件夹

#### Firefox
1. 下载所有文件到本地文件夹
2. 将 `manifest.json` 重命名为 `manifest-chrome.json`
3. 将 `manifest-firefox.json` 重命名为 `manifest.json`
4. 打开Firefox，进入 `about:debugging`
5. 点击"此Firefox"
6. 点击"临时载入附加组件"
7. 选择 `manifest.json` 文件

## ✨ 核心功能

### 1. 🕵️ 智能数据收集
- 自动收集你在B站的浏览行为
- 分析你观看的分区和UP主偏好
- 生成详细的兴趣画像

### 2. 🎯 直接推荐算法控制
- **一键应用历史推荐**：点击即可切换到过去某个时间点的推荐状态
- **预设热门推荐**：提供科技、生活、历史、军事、娱乐、游戏、知识等热门推荐算法
- **破除信息茧房**：随机化推荐算法，接触更多样化的内容
- **实时预览**：在应用前预览历史画像内容
- **静默操作**：不会弹出多个页面，用户体验更佳

### 3. 📊 兴趣画像管理
- 查看当前兴趣画像
- 浏览历史偏好记录
- 分析兴趣变化趋势

## 🚀 使用方法

### 使用推荐控制功能

#### 方法一：应用历史推荐
1. 在B站页面点击插件图标
2. 在"历史画像切换"部分找到想要的时间点
3. 点击"🎯 应用此推荐"按钮
4. 确认操作后，插件会自动：
   - 静默清除当前浏览历史
   - 模拟该时期的用户行为
   - 重新设置偏好
   - 刷新页面应用新推荐

#### 方法二：应用预设推荐算法
1. 如果没有历史数据，插件会显示预设选项
2. 选择你感兴趣的类别：科技、生活、历史、军事、娱乐、游戏、知识
3. 点击"🎯 应用"按钮
4. 插件会静默应用该类型的推荐算法

#### 方法三：一键清除信息茧房
1. 点击"🚀 一键清除信息茧房"按钮
2. 插件会应用"随机"推荐算法
3. 让你接触到更多样化的内容

## 🔧 技术原理

### 推荐算法更改机制
插件通过以下方式影响B站的推荐算法：

1. **静默清除浏览历史**：使用API直接清除记录，不打开新页面
2. **静默模拟用户行为**：使用fetch API访问相关内容，不弹出标签页
3. **静默设置用户偏好**：直接设置兴趣标签，不打开设置页面
4. **页面刷新**：重新加载页面以应用新的推荐

### 数据收集机制
- 在视频页面自动收集：视频ID、分区、UP主、时间戳
- 每日聚合生成兴趣画像
- 本地存储，保护隐私

### 跨浏览器兼容性
- 自动检测浏览器类型（Chrome/Chromium/Firefox）
- 使用统一的API接口
- 支持不同浏览器的权限系统

## 🛡️ 隐私保护

- 所有数据仅存储在本地
- 不上传到任何服务器
- 不收集个人敏感信息
- 可随时清除所有数据

## ⚠️ 注意事项

1. **使用环境**：请在B站页面使用推荐控制功能
2. **操作时间**：推荐算法更改可能需要几分钟时间
3. **浏览器版本**：Firefox需要109.0或更高版本
4. **权限要求**：需要访问B站相关页面的权限
5. **静默操作**：所有操作都在后台进行，不会弹出多个页面
