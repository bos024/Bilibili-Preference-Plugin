# Bilibili Preference Plugin

一个用于 B 站的本地推荐管理扩展，支持内容过滤、兴趣画像和自主探索。

## 功能

- 按视频、UP 主、UID 和标题关键词过滤推荐卡片
- 三种使用模式：均衡、聚焦、探索
- 根据有效播放时长生成本地兴趣统计
- 从公开热门和排行榜获取候选视频，按偏好与多样性重排序
- 保存配置快照、稍后看列表，支持 JSON 导入导出

## 安装

无需构建，直接加载源码目录。

**Chrome / Edge**：打开 `chrome://extensions`，启用开发者模式，选择“加载已解压的扩展程序”，选择本项目目录。

**Firefox**：打开 `about:debugging#/runtime/this-firefox`，选择“临时载入附加组件”，打开 `manifest.json`。临时扩展在浏览器重启后需要重新载入。

从旧版升级时尽量沿用原扩展目录；若扩展 ID 改变，旧版浏览器存储不会自动迁移。

## 使用

打开 B 站后，将鼠标移到视频卡片上，可以屏蔽该视频或 UP 主。点击工具栏图标可切换模式；在控制台中管理主题权重、屏蔽规则、探索内容和历史配置。

“聚焦”模式只对能识别主题的卡片执行主题过滤；“探索”模式在控制台重排序公开候选内容。扩展不会修改 B 站服务端推荐算法。

## 隐私与限制

观看记录和设置保存在浏览器本地。仅在主动获取探索内容时请求 B 站公开接口，不上传本地兴趣画像。公开接口可能因平台限制而不可用；视频卡片过滤依赖 B 站页面结构，网站更新后可能需要适配。

## 开发

运行 `npm test` 执行本地测试。项目不需要第三方运行时依赖。
